## Overview

The projects in this section demonstrate how relational databases can be designed, implemented, and queried to support dependable business operations and analysis. The work covers requirements development, entity-relationship modeling, normalization, table relationships, data integrity, PostgreSQL implementation, and SQL queries designed to retrieve and interpret information across connected data sources.

Together, these projects show the progression from understanding a business problem to designing a structured data model and using SQL to produce accurate, decision-ready information.

---

## Projects

### ⭐ [Johnson Video Relational Database System](./johnson_video_relational_database)

A PostgreSQL database designed to replace a video-rental company’s paper-based approach to customer accounts, inventory, purchasing, and rentals. The project translates operational requirements into a relational model and uses SQL to support sourcing, inventory, rental, customer, and marketing decisions.

**Technologies:** PostgreSQL • SQL • Relational Database Design • Entity-Relationship Modeling
